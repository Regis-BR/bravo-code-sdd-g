# Code of Conduct

## Princípios

Este projeto é mantido para uso interno de RNZ Tech Ltda, mas é público no GitHub. Para qualquer interação (Issues, PRs, Discussions, comments), valem regras simples:

- **Seja técnico, seja específico.** Comments vagos não ajudam ninguém.
- **Argumentos > opiniões.** Disagreement é bem-vindo se vier com dados, código, ou referência verificável.
- **Sem ataques pessoais.** Crítica vai sempre ao código/decisão, nunca à pessoa.
- **Sem spam, sem self-promotion.** Issue não é canal de marketing.
- **Respeite o escopo.** Se uma Issue está fora do escopo do projeto, seja direto: `wontfix` com explicação.

## Aplicação

O mantenedor (`@Regis-BR`) reserva o direito de:

- Editar/remover comments que violem estas regras
- Bloquear usuários reincidentes
- Fechar Issues/PRs sem discussão extensa quando o tom é destrutivo

## Reportes

Comportamento abusivo ou fora destas diretrizes: **regis@rnztech.com**
